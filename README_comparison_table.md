## 🆚 Existing Apps vs AI Quiz Arena

| Feature | Quizizz / Kahoot | Testbook / Adda247 (exam prep apps) | ChatGPT / Gemini (generic AI) | **AI Quiz Arena (Ours)** |
|---|---|---|---|---|
| Quiz banane ka tareeka | Teacher/user manually sawal likhta hai | Pehle se bane fixed test series | Har baar prompt likhna padta hai | **AI khud quiz banata hai: Topic, PDF, Notes ya Photo/Camera se** |
| Apne notes / PDF se quiz | Limited ya paid | ❌ Nahi | Manual copy-paste | **✅ PDF upload + handwritten notes ki photo (vision model)** |
| Govt exam PYQ + mock | ❌ | ✅ (zyadatar paid) | ❌ Exam pattern nahi pata | **✅ SSC CGL, RRB NTPC, Banking, UP Police, UPSC/PCS, UP CNET, NEET UG, JEE Main: official marking (negative marks) + timer ke saath** |
| Adaptive difficulty | Limited | Limited | ❌ | **✅ Sahi par sawal mushkil, galat par aasaan** |
| Question types | Mostly MCQ | MCQ | Jo prompt me likho | **MCQ, True/False, Numerical, Short answer (AI grading)** |
| Modes | Live game | Test mode | ❌ | **Practice, Exam aur Survival (3 lives)** |
| Doubt solving | ❌ | Limited / paid | ✅ Par quiz se connected nahi | **✅ Built-in Doubt Solver tab, galat sawalon ka AI explanation + study plan** |
| Language | English (Hindi limited) | Hindi + English | Jo prompt me likho | **Hinglish, English aur हिन्दी: poora UI aur quiz teeno me** |
| Gamification | Points, leaderboard | Rank | ❌ | **XP, levels, streak, badges** |
| Voice (read-aloud) | ❌ | ❌ | Limited | **✅ Question sunne ka option (TTS)** |
| Repeat sawal se bachav | ❌ | ❌ | ❌ | **✅ Seen-questions tracking, har baar naye sawal** |
| Login | Email/Google | Email/Phone | Account | **✅ Email / Mobile OTP (guest mode bhi)** |
| Progress save / report | Basic | Paid analytics | ❌ | **✅ History, bookmarks, downloadable report aur progress backup** |
| Cost | Free + paid plans | Mostly paid | Free + paid plans | **✅ Free & open-source (Groq API + Streamlit)** |
| Tech | Closed-source | Closed-source | Closed-source | **Python, Streamlit, Groq LLMs (gpt-oss, Llama)** |

**Hamara USP:** Apne hi notes/PDF se instant quiz + govt exam ka asli marking pattern + Hinglish support, sab free me.
